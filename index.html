      02

      三档模型，三种立场

      SOLVER

      强推理

      负责把题做出来，允许多路独立候选。默认采用最稳健、便于完整核验的路线，而不是最炫的路线。

      VERIFIER

      独立第二模型

      先自行重算，再逐目标、逐步骤审核。主动找反例、遗漏情形、循环论证；候选自己的 checks 不算证据。

      ADJUDICATOR

      第三方仲裁

      逐目标规范化比较答案，按数学 / 物理正确性判断。数值相同不代表证明有效，两份一致也不免于核对。

      开启「强制不同模型族」后，三档 family 两两不同，同源直接抛错：「禁止同源模型自我复核或自我仲裁」。默认不强制，但会给出「审核独立性有限」的警告——不静默改变既有语义。

      03

      红线不是判断对错，是拒绝措辞

      扫描解答者的叙述字段：understanding / approach / steps.claim / steps.justification。命中即降级并写明位置，不删除答案。否定语境有 14 字豁免窗口，避免「此处不得写显然成立」被自己误伤。

      04

      证据量，不是置信度

      结果页不出现 0–1 的「正确率」。展示的是可核验的覆盖率与独立性：核验了几个目标、几个步骤、审核模型是否独立、是否形成交叉一致。

      confidence 是程序化证据强度（high / medium / low），不是模型自报的概率。样本或独立性不足时，结果页明确写「证据不足，不能判定为 verified」，并逐条给出原因。

      05

      这里不会发生什么

        这八条随每份结果输出。它们不是免责声明，而是产品的行为约束。

        06

        边界

        不承诺绝对正确

        verified 只表示通过本流程的程序化检查，不是数学证明的终审。审核模型与仲裁模型只增加独立性，不构成正确性保证。

        真实端点未验

        参数映射只在 mock 上验证过。遇到 CORS、额度或参数不兼容，页面会给出可操作的中文错误，不假装成功。

        无人工金标集

        没有人工标注的题目集与对照实验，因此本产品不提供任何「正确率提升 X%」的数字。

        密钥的极限

        纯静态 BYOK 无法抵御解锁期间的 XSS。密钥默认只在内存，降低的是持久化暴露面，不是硬件级隔离。

        本页是 v11.0 方案的浏览器实现，v11.1 在其上补了学习闭环（档案仪表盘、程序化重测、答疑卡点）。判题链路、红线、证据量、图片门槛与状态语义与文档一致；OCR、资料检索与三档调用为前端近似实现，不冒充生产包的实测结论。

        07

        答疑不是判题的简化版

        判题对「结论是否正确」负责，答疑对「你理解到哪一步」负责。两者门槛不同，所以不能共用同一个状态标签——答疑回答永远不会显示 verified，它只标「未经程序化验收」。

        先定位

        复述你卡在哪

        开头先说清它理解到的位置（哪一行、哪个等式）。描述不足以定位时，直接问缺什么，不猜着讲。

        可检验

        每个断言都要能验

        等式、量纲、特例、极端情形、反例，至少给一种。不用「显然」「易证」代替论证。

        留半步

        只指出第一处错

        你的演算出错时，说清第一处错在哪、为什么错，然后让你自己往下改，不甩一份完整解答覆盖你的过程。

        答疑同样受红线约束：不编造定理名与数据，条件不足就说缺什么。它与判题共享同一套数据边界提示词，题面、演算、资料片段都只作为数据，不作为指令。

        08

        判完之后，笼子继续管学习

        判定不是终点。每条没过验收的记录都会进入档案，由程序做三件事：归类卡点、排重测、留答疑的脚印。这里没有「标记已解决」，闭合只有一种方式——重判通过。

        DASHBOARD

        弱点不是感觉，是计数

        最近未通过的记录按降级原因聚类：几次卡在图片未核对、几次证据不足。统计在本地完成，不经过任何模型。

        RETEST

        重测由程序排期

        没过的题在 3 天 天后置顶提醒。重判时把上次的降级原因和这次并排展示；通过后原记录自动闭合，失败则继续留在队列。

        TUTOR

        卡点也留档

        答疑结束时，「你在哪一步停下」和回答定位到的那一行会写入档案，单独打 tutor 标签，永远不碰 verified 语义。

        档案页不出现「正确率 X%」，也不提供账号、云同步或分享链接。前者会背叛「证据量不是置信度」，后者会把「无后端」这块骨头抽掉。

        密钥只存在内存句柄里

        判题纪律

        安全边界

        纯静态 BYOK 无法做到密码学意义上的绝对不泄露：XSS 若在密钥解锁期间执行，仍可 hook 请求读取到 Key。「只存内存」降低的是持久化暴露面，不是硬件级隔离。根治方案是服务端代理 + HttpOnly 会话，那不属于纯前端直连模式。

        • 非 HTTPS 端点一律拒绝，仅 localhost 放行。
        • 请求使用 credentials: omit / referrerPolicy: no-referrer / cache: no-store。
        • 错误信息统一经 redact() 脱敏，不显示 Bearer 头与请求体。
        • 空闲 15 分钟、页面隐藏 3 分钟、pagehide 触发自动锁定。

        这家能不能直连？

        浏览器直连要求服务商显式允许 CORS。返回 Failed to fetch 时，通常是服务商不允许浏览器跨域，而不是 Key 错误。此时只能改用允许 CORS 的兼容端点。
